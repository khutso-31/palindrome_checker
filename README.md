# Palindrome Checker

A simple web app that checks whether a word or phrase is a palindrome.

## Features

- Accepts text input
- Ignores case and non-alphanumeric characters
- Shows a clear success or error result

## Run it locally

Open [index.html](index.html) directly in a browser.

If you prefer a local server, you can also run:

```bash
cd "c:/Users/Admin/Desktop/polindrome checker"
python -m http.server 8000
```

Then open the browser to the generated local URL, although direct file opening is the most reliable option in this environment.
